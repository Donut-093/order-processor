Python-скрипт для пакетной обработки JSON-файлов, расчёта метрик и генерации сводных отчётов. 

Разработан как решение для автоматизации рутинных задач учёта (например, расчёт стоимости материалов на основе входящих данных).

- **Python 3.x**
- Встроенные библиотеки: `json`, `pathlib`

## Что умеет скрипт
1) Автоматически сканирует целевую папку и находит все файлы с расширением `.json`.
2) Извлекает данные (вес, цена материала) для каждого заказа.
3) Вычисляет итоговую стоимость по заданной формуле.
4) Формирует единый сводный отчёт `total_report.json`.
5) Масштабируем: легко адаптируется под любые структуры JSON-данных (склады, логистика, учёт пациентов).

## Как запустить
1) Убедитесь, что установлен Python 3.x.
2) Поместите ваши JSON-файлы с данными в папку `orders_folder`.
3) Запустите скрипт в терминале:
   ```bash
   python process_folder.py
