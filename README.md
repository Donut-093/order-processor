# Order Processor (Автоматизация обработки заказов)

Набор Python-скриптов для пакетной обработки данных, расчёта метрик и генерации сводных отчётов. Разработан как модульное решение для автоматизации рутинных задач учёта (например, расчёт стоимости материалов для 3D-печати в протезно-ортопедических мастерских на основе входящих данных).

## 🛠 Технологический стек
- **Python 3.x**
- Встроенные библиотеки: `json`, `pathlib`
- Сторонние библиотеки: `pandas`, `openpyxl`

## ⚙️ Возможности проектов

### 1. Базовый процессор (`process_folder.py`)
- Автоматически сканирует целевую папку и находит все файлы с расширением `.json`.
- Извлекает данные (вес, цена материала) для каждого заказа.
- Вычисляет итоговую стоимость и формирует единый сводный отчёт.

### 2. Продвинутый процессор (`advanced_order_processor.py`)
- **Поддержка смешанных форматов:** одновременно обрабатывает `.json` и `.xlsx` файлы в одной папке.
- **Категоризация:** автоматически присваивает заказам статус ("дорогая печать" / "дешёвая печать") на основе пороговых значений.
- **Аналитика:** выводит в консоль сводную статистику (общее количество заказов, общая сумма, средняя стоимость, самый дорогой заказ).
- **Экспорт:** генерирует чистый, форматированный Excel-отчёт (`final_report.xlsx`) без технических индексов.

##  Как запустить
1. Убедитесь, что установлен Python 3.x и библиотеки.
2. Поместите ваши файлы с данными (`.json` или `.xlsx`) в целевую папку.
3. Запустите нужный скрипт в терминале:  
   `python advanced_order_processor.py`
4. Проверьте сгенерированный файл `final_report.xlsx` и вывод в консоли.
